# Полезное для расчетов

Веб-версия рабочей таблицы конструктора: справочники, калькуляторы и чек-листы РД.


## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`

## Возможности

- Все листы исходного Excel — вкладки сверху
- Интерактивные расчёты с логикой формул
- Шкалы армирования с копированием кодов для ЛираСАПР
- Чек-листы с выгрузкой в Excel
- Калькулятор справа (только на десктопе; на мобильных скрыт)
